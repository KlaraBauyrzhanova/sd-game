# SD-Game — Симулятор проектирования систем
SD-Game — интерактивный проект для моделирования нагрузки и оценки архитектурных решений при проектировании высоконагруженных систем.

Идея проста: выбрать масштаб системы, экспериментировать с архитектурой, моделировать нагрузку и исследовать, как различные технические решения влияют на производительность, масштабируемость, отказоустойчивость и стоимость инфраструктуры.

🚧 Статус проекта: в разработке

💡 Идея проекта
Спроектировать систему для 10 000 пользователей — совсем не то же самое, что для 1 000 000 или 10 000 000+ пользователей.

SD-Game призван наглядно показать эту разницу с помощью интерактивных симуляций проектирования систем. Вместо того чтобы опираться исключительно на теорию, пользователь сможет экспериментировать с архитектурными решениями, изучать компромиссы и наблюдать, как система ведёт себя при росте нагрузки.

Проект задуман как инструмент для обучения и экспериментирования с архитектурой высоконагруженных систем.
